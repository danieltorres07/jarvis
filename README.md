# Jarvis — repo de status

Repositório privado usado só pela rotina automática de resumo diário (`jarvis-status`).

Contém uma cópia das regras do projeto (`CLAUDE.md`), definições de agentes/squads e a memória de projetos ativos — o suficiente pra um agente na nuvem montar um resumo de status real todo dia às 8h.

**Não contém:** fotos, PDFs, dados de cliente/paciente, chaves de API ou qualquer coisa sensível. Isso fica só no Mac local.

Este repo é atualizado manualmente por enquanto (sem sync automático com o Mac).
